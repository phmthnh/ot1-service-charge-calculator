## MÔ TẢ BÀI TẬP
Xây dựng ứng dụng Windows Forms tính tổng tiền dịch vụ có áp dụng giảm giá.

**Công thức:** Tổng tiền = (Đơn giá × Số lượng) × (100 - % Giảm) / 100

**Tính năng:**
- Nhập Đơn giá dịch vụ, Số lượng khách, % Giảm giá
- Validate dữ liệu (số hợp lệ, không để trống, % trong khoảng 0–100)
- Hiển thị kết quả tổng tiền định dạng VNĐ
- Nút Làm mới để nhập lại
